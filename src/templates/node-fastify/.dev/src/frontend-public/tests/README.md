# Tests — frontend-public

## Estructura

```
tests/
├── unit/features/_template/    ← copiar para cada feature
├── e2e/features/_template/     ← copiar para cada feature

```

## Ejecutar

```bash
npm run test          # unit watch
npm run test:run      # unit una sola vez
npm run test:e2e      # E2E con Playwright
```
