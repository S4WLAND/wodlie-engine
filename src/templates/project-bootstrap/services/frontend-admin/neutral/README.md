# Frontend Admin

Preset `neutral` para el panel administrativo.

Este servicio nace sin framework UI preconfigurado. El objetivo es dejar:

- estructura screaming por módulos
- documentación y contexto base
- `.env.example`
- carpetas de tests y estilos listas

## Estructura esperada

```text
frontend-admin/
├── src/
│   ├── app/
│   ├── modules/
│   ├── shared/
│   └── styles/
└── tests/
    ├── unit/modules/
    ├── e2e/modules/
    └── non-functional/
```
